# Amarcode documentation

Starlight on Astro, mounted at `/docs/` alongside the existing React landing.
Markdown/MDX pages live in `src/content/docs/`; the explicit sidebar lives in
`astro.config.mjs`. The theme reuses the landing's Cormorant font asset and adds
Geist for long-form body text. Search is generated by Starlight/Pagefind at build
time; it is available in production and preview, not the development server.

From the repository root:

```sh
bun install
bun run docs:dev
bun run docs:check
bun run docs:build
bun run docs:preview
```

Open `http://localhost:4321/docs/`. Run `bun run landing:dev` in another terminal
for the landing site; its development server proxies `/docs` to Astro.

`bun run landing:build` builds both workspaces and assembles one static output in
`crates/landing/dist/`, including `/docs`, its assets, Pagefind index, and sitemap.
Keep the existing Vercel landing project rooted at `crates/landing`, with its
`bun run build` command and `dist` output. No additional docs service or rewrite
is needed in production. Preview that combined output with
`bun run landing:preview`.

Set `SITE_URL` to the deployment origin when building for a different domain.
The docs base remains `/docs`; internal content links intentionally use it.

To add a guide, create a `.md` or `.mdx` file with `title` and `description`
frontmatter, add its slug to the sidebar, and verify links in the built site.
Use the built-in Starlight components for callouts and code examples. Theme
changes belong in `src/styles/amarcode.css`; the brand header override is
`src/components/SiteTitle.astro`.

Favicons reuse the desktop's multi-resolution `.ico` and 180×180 Apple icon.
The SVG icon remains available for modern browsers. Sharing uses a copy of the
landing's social preview under `/docs/social-preview.png`; refresh this copy
when updating the landing preview. `Head.astro` preserves Starlight's generated
canonical/Open Graph metadata and adds page-specific Twitter titles and
descriptions. The social image URL uses the configured `SITE_URL` origin.
