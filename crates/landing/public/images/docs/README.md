# Overview icons

EOS icons supplied for the Amarcode handbook overview, downloaded from:

- Desktop: https://cdn.iconsroom.com/eos-icons/application.svg
- Daemon: https://cdn.iconsroom.com/eos-icons/background-tasks.svg
- Coding agents: https://cdn.iconsroom.com/eos-icons/compass.svg

The SVGs are served locally and used as CSS masks to inherit the handbook's
light and dark theme colors.

The overview title banner uses an alpine lake photograph by Anna Scarfiello:
https://unsplash.com/photos/lake-in-the-middle-of-mountains-dJcMnu9kRHs
Image source: https://images.unsplash.com/photo-1622744678361-64f90c825820
License: https://unsplash.com/license

`alpine-lake.webp` is served locally. A uniform translucent paper/ink overlay keeps the
title readable while retaining the photograph's natural colors. The homepage's
`../grain.svg` texture is applied at 5% opacity.
