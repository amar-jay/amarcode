## Three parts, one workspace

<div className="docs-flow" aria-label="The desktop connects to the daemon, which runs coding agents">
  <div className="docs-flow-part">
    <span className="docs-part-icon docs-part-icon-application" aria-hidden="true"></span>
    <strong>Desktop</strong>
    <span>Read, write, and review.</span>
  </div>
  <div className="docs-flow-part">
    <span className="docs-part-icon docs-part-icon-background" aria-hidden="true"></span>
    <strong>Daemon</strong>
    <span>Keep the work running.</span>
  </div>
  <div className="docs-flow-part">
    <span className="docs-part-icon docs-part-icon-compass" aria-hidden="true"></span>
    <strong>Coding agents</strong>
    <span>Bring your tools and models.</span>
  </div>
</div>

The desktop is where you read, write, and review. The daemon keeps your chat history, works with project files, and runs agents through the Agent Client Protocol (ACP). It can live on your computer or a remote host.
