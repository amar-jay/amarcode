## Reopen a chat

Each chat remembers its project. Select it in the sidebar to return to the messages. A new chat can use the folder from **Settings → Agent defaults**.

Messages stay after you close the desktop.

## Slash commands

Type `/` to see commands from the selected agent. A command in one agent may not exist in another.

## Session options

If the agent offers a model or a mode, those controls appear in the composer.

## Stop a turn

The stop control cancels the current prompt. Earlier messages stay, and you can send another prompt.

Closing the app is not the same as stopping. The daemon can keep working.
